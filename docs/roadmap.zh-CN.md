# TAO OSINT 路线图

[English](roadmap.md) · **简体中文**

## v0.1 — 工具目录基础

目标：建立可持续维护的 OSINT 工具收藏库。

计划：

- 分类体系
- 统一工具元数据
- 初始工具目录
- YAML 校验
- 收录规范
- 负责任使用说明
- External / TAO Optimized / TAO Built 分类
- External / Integrated 交互模式

完成标准：

- 工具使用统一结构
- 每个工具都有官方入口
- 用途能快速理解
- 费用 / 账号 / 平台信息清晰
- 重要局限被记录

## v0.2 — 搜索与陈列

目标：让工具库真正适合日常浏览。

计划：

- 响应式首页
- 分类浏览
- 全局搜索
- 标签
- 平台筛选
- 免费 / 付费筛选
- 账号要求信息
- 高密度目录式工具条目
- 多种排序方式
- 最近审阅时间
- 官方入口快速跳转
- 中文 / English 实时切换

## v0.3 — 收藏与合集

目标：让 Tao-OSINT 成为个人 OSINT 收藏库。

计划：

- 收藏
- 自定义合集
- 浏览器本地持久化
- 最近打开
- 置顶
- 合集导入 / 导出
- 可选个人备注

第一阶段不要求账号系统。

## v0.4 — 少量 TAO 内置工具

目标：只集成真正值得直接使用的项目。

当前：

- Photo Stargazing Positioning

后续只有在确实解决明确缺口时才增加。

不为了增加功能数量而重复实现成熟外部工具。

## v0.5 — 维护与贡献

计划：

- 工具提交模板
- Last reviewed 日期
- 失效链接检查
- Catalog CI 校验
- Deprecated 状态
- 更新日志
- 社区建议

## v0.6 — 可选工作流

目标：用轻量指南连接已有工具。

可能包括：

- 反向图片验证
- 元数据检查
- 基础地理定位
- 太阳 / 阴影判断
- 网页存档查询
- URL / 网站检查

工作流仍然次于“收集、搜索、收藏”核心体验。

## v1.0 — 稳定 OSINT 工具收藏平台

稳定版本应具备：

- 持续维护的工具目录
- 清晰分类
- 快速搜索与筛选
- 收藏与合集
- 简洁工具说明
- 费用 / 账号 / 平台信息
- 官方入口
- 少量内置 TAO 工具
- 中英文界面
- 移动端体验
- 贡献规范
