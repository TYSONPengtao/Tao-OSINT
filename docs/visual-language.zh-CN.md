# TAO OSINT 视觉语言

[English](visual-language.md) · **简体中文**

## 目标

TAO OSINT 使用一套统一、克制的视觉系统来承载不断增长的工具目录。

整体应该更像一个专业技术目录，而不是装饰性很强的仪表盘。

## 分类图标

每个分类对应一个内置 SVG 线性图标。

统一规则：

- 24 × 24 SVG 画布
- 1.65 px 描边
- 圆角端点和连接
- 不使用 Emoji
- 不依赖外部图标 CDN
- 使用 `currentColor` 单色渲染
- 激活和分类强调使用 TAO 绿
- 非激活状态使用低对比灰色

同一个分类图标必须一致出现在：

- 分类导航
- 首页热门分类入口
- 工具卡片
- 最近访问
- 工具详情弹层

## 信息层级

### 一级 — 工具身份

最高对比：

- 工具名称
- 主要操作
- 当前分类

### 二级 — 用途

中等对比：

- 简短说明
- 分类
- 平台

### 三级 — 元数据

低对比：

- 标签
- 是否需要账号
- 最近审阅日期
- 次级徽章

## 工具卡片

卡片必须适合未来 100+ 工具规模，不能因为视觉装饰而过度膨胀。

列表模式优先保证扫描效率。

网格模式可以更有视觉表现，但不能变成巨大的宣传卡片墙。

悬停反馈保持克制：

- 向上 1 px
- 边框增强
- 左侧出现 2 px TAO 绿色分类指示线

## 首页首屏

首屏采用：

- 低对比网格纹理
- 简洁产品定位
- 浏览工具库主操作
- 收藏快捷入口
- 少量高频分类入口

目标是在一屏内说明“这是什么”，同时不把真正的工具目录推得太远。

## 工具详情

详情弹层使用分类图标作为主要视觉锚点。

强调顺序：

1. 分类图标
2. 工具名称
3. 工具说明
4. 打开 / 使用按钮

平台、账号和审阅日期等元数据放在说明之后。

## 色彩

核心配色：

```text
背景              #080a09
面板              #0f120f
抬升面板          #141814
主要文字          #f1f4ee
次要文字          #939c91
TAO 强调色        #c8ff00
```

分类之间主要依靠**图标形状 + 分类文字**进行识别，不给 21 个分类分别分配杂乱颜色。

## 中英文排版

中文和英文必须使用同一套结构。

不要为两种语言维护不同视觉模板。

组件应同时容纳更长的英文标签和更紧凑的中文文本，而不改变整体层级。
