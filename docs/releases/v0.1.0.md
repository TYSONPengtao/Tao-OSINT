# TAO OSINT v0.1.0

**Release date:** 2026-10-04

TAO OSINT v0.1.0 establishes the first usable version of the project as a curated OSINT tool collection, showcase and bookmark platform.

## Highlights

- **51 curated tools**
- **21 categories**
- **Chinese / English**
- Search, filters and sorting
- Local browser favorites
- Recently opened tools
- List and grid views
- Mobile-friendly filtering
- Unified category icon system
- Tool detail view
- One directly integrated TAO tool

## What TAO OSINT is

TAO OSINT is primarily a curated collection.

Most entries:

- describe a useful OSINT tool
- classify it
- show cost, account and platform information
- expose tags and review date
- open the official source

Direct integration is intentionally rare.

## First Integrated Tool

### Photo Stargazing Positioning

A TAO-optimized night-sky image positioning prototype with:

- Python core
- reproducible sample
- tests
- candidate clustering
- JSON / CSV export
- bilingual browser interface

Its output is a geometric clue, not guaranteed ground truth.

- recent tools

## Known Limitations

- GitHub Pages requires one-time repository owner enablement
- catalog metadata and frontend data are still maintained separately
- favorites are local to the browser
- no account sync
- no community submission workflow yet
