# TAO OSINT v0.1.0

**发布日期：** 2026-10-04

TAO OSINT v0.1.0 是项目第一版真正可用的 OSINT 工具聚合、陈列与收藏平台。

## 核心内容

- **51 个精选工具**
- **21 个分类**
- **中文 / English**
- 搜索、筛选、排序
- 浏览器本地收藏
- 最近访问
- 列表 / 网格模式
- 手机端完整筛选
- 统一分类图标体系
- 工具详情
- 1 个 TAO 内置工具

## Tao-OSINT 是什么

Tao-OSINT 的主体仍然是**工具收藏库**。

绝大多数条目负责：

- 说明工具用途
- 分类
- 展示费用 / 账号 / 平台
- 标签和审阅日期
- 跳转官方入口

直接内置使用只保留少量真正值得维护的 TAO 工具。

## 第一个内置项目

### Photo Stargazing Positioning

经过 TAO 优化的星空照片定位实验工具，包含：

- Python 核心
- 可复现样例
- 测试
- 候选点聚类
- JSON / CSV 导出
- 中英文浏览器界面

结果属于几何线索，不应被当作绝对精确位置。

## 界面

v0.1.0 已具备：

- 高密度目录式浏览
- 21 类统一图标
- 中英文工具说明
- 收藏
- 最近访问
- 可删除筛选标签
- 列表 / 网格模式
- 每次 18 条分批加载
- 桌面 / 平板 / 手机响应式界面

## 已知限制

- GitHub Pages 仍需要仓库所有者手动启用一次
- catalog YAML 与前端数据目前仍有双份维护
- 收藏只保存在本地浏览器
- 没有账号同步
- 暂无社区提交工作流

## 下一步

2. 让 catalog YAML 成为前端唯一数据源
3. 增加自定义合集
4. 自动检测失效链接
