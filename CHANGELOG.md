## [0.1.0] - 2026-10-04

### Added

- Collection-first TAO OSINT product architecture
- 51 curated OSINT tools
- 21 categories
- Chinese / English interface
- Search by name, description, tags and platform
- Category, platform, cost and interaction filters
- Favorites stored locally in the browser
- Recently opened tools
- List / grid view modes
- Incremental rendering for large catalogs
- Tool detail dialog
- Keyboard search shortcut
- Mobile filter drawer
- Unified SVG icon system for all categories
- Bilingual visual-language documentation
- Bilingual README and roadmap documentation
- Photo Stargazing Positioning as the first integrated TAO Optimized tool
- GitHub Pages deployment workflow and setup documentation

### Product Principle

Most tools are collected, categorized, described and linked to their official source.

Only a small number of selected TAO tools are directly integrated.
