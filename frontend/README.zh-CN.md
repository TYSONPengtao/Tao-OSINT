# TAO OSINT 前端

[English](README.md) · **简体中文**

TAO OSINT 的主要前端是一个双语、响应式的 **OSINT 工具聚合 / 陈列 / 收藏界面**。

## 当前版本

打开：

```text
frontend/index.html
```

## 主要功能

- 中文 / English 即时切换
- 自动记忆语言选择
- 工具分类导航
- 全局搜索
- 外部工具 / 内置工具筛选
- 免费 / 部分免费 / 付费筛选
- 平台筛选
- 精选 / 名称 / 分类 / 最近审阅排序
- 高密度工具目录展示
- 点击标签快速搜索
- 浏览器本地收藏
- 仅看收藏
- External / Integrated / TAO Optimized 标识
- 工具最后审阅时间
- 官方工具快速跳转
- TAO 内置工具直接打开
- 桌面 / 平板 / 手机响应式排版

## 设计方向

界面参考 GitHub Topics 的工具/仓库浏览逻辑：

```text
主题
 ↓
数量
 ↓
筛选 / 排序
 ↓
高密度条目
 ↓
标签
 ↓
平台 / 审阅时间 / 使用状态
```

但保留 TAO OSINT 自己的暗色视觉和收藏型产品定位。

## 原则

大多数工具只负责：

- 收集
- 分类
- 展示
- 收藏
- 跳转官方入口

只有少量 TAO 精选工具直接内置使用。

当前收藏和语言设置都优先保存在浏览器本地，不需要后端。
