# TAO 星空照片定位 — 优化版

[English README](README.md)

这是对原始学习项目进行安全重构后的 TAO OSINT 工具版本。

## 当前能力

- 观测数据与算法代码分离
- 数值异常诊断
- JSON / CSV 导出
- 自动生成全部数学位置候选
- 地理候选聚类
- 浏览器 Web MVP
- **中文 / English 实时切换**
- Web 计算全部在浏览器本地完成，不上传观测数据

## Web 版

打开 `web/index.html`。

页面右上角可以在 **中文 / English** 之间切换，语言选择会记录在浏览器中。

当前支持载入示例、编辑 Observation JSON、计算焦距、生成经纬度候选、识别主地理聚类、查看全球候选分布、打开 OpenStreetMap，以及导出 JSON / CSV。

## 示例结果

- 平均焦距约 **554.485 px**
- 6 个数学候选
- 3 个候选形成主聚类
- 聚类中心约 **33.6° N, 115.3° E**

## 重要限制

该方法对恒星识别、时角、像素坐标、天顶估计、镜头畸变和相机投影都比较敏感。主聚类只是 **OSINT 候选线索**，不是精确定位真值。

应结合地形、地标、时间、天气、地图、太阳/阴影和 Stellarium/星图等独立证据继续验证。
